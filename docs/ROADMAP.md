# Roadmap

This roadmap describes direction rather than dates. Current support is defined by the tested source.

## Current foundation

- maintain the garage-to-race playable loop and persistent progression
- continue the asset-driven full-frame presentation migration
- keep vehicle paint/presentation and race-session rules regression-tested

## Near-term priorities

- deepen hands-on part installation and garage interaction
- improve race control/fidelity while preserving deterministic testable state
- replace remaining transitional primitive rendering with authored presentation

## Longer-term direction

- expand cars, opponents, parts, events and progression without fragmenting the core state model
- broaden platform support after the game/core contract remains stable

## Admission rule

New work needs clear ownership and a credible validation path. Reference material or an attractive idea is not automatically a product commitment.

## Completion rule

Implementation, tests, user-visible behaviour and maintained documentation must agree before an item is considered complete.
